# SQL_Data_Analytics_Project

# Sales Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing sales data using SQL to uncover business insights related to sales performance, customer behavior, product performance, and sales trends.

The goal is to transform raw sales data into meaningful insights that can support data-driven business decisions.

Using SQL Server, I performed exploratory data analysis (EDA) and advanced analytics to understand the company's sales performance, identify top-performing products and customers, and analyze trends over time.

## 🎯 Business Objectives

- Analyze overall sales performance and key business metrics.
- Identify top-performing products and product categories.
- Understand customer purchasing behavior and customer segments.
- Track sales trends over time and identify patterns.
- Compare product and customer performance.
- Generate actionable insights to support business decision-making.

## 🛠️ Tools & Technologies

- **SQL Server** — Data querying and analysis.
- **T-SQL** — Data exploration, aggregations, joins, and advanced analytical queries.
- **Git & GitHub** — Version control and project documentation.

## 🔍 Analysis Performed

### 1. Exploratory Data Analysis

- Explored database tables, columns, and relationships.
- Examined date ranges and data distributions.
- Analyzed key measures, including sales, revenue, and customer counts.
- Identified top-performing products and customers.

### 2. Advanced Analytics

- Analyzed sales trends over time.
- Calculated running totals and cumulative metrics.
